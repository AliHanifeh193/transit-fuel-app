## اجرای آزمایشی

با Node.js 24 LTS در مسیر ریشه مخزن اجرا کنید. پایگاه SQLite به کمک ماژول داخلی Node ساخته می‌شود و وابستگی npm ندارد.

```bash
node server/app.js
```

نشانی محلی `http://localhost:8100` و مسیر سلامت `/api/health` است. برای آزمایش شرکت، مدیر اولیه را با فرمان `node server/app.js init-admin USER NAME` بسازید. رمز را از ورودی استاندارد امن به برنامه بدهید. ابتدا از مسیر پایگاه داده مطمئن شوید و داده آزمایشی را در پایگاه جدا نگه دارید.

```bash
node --test tests/*.test.js
python3 tests/browser.py
```

آزمون مرورگر به Python Playwright و Chromium نیاز دارد. در صورت نیاز، مسیر Chromium را با `CHROMIUM_PATH` تعیین کنید. آزمون‌ها در پوشه‌های موقت، با داده و حساب‌های مصنوعی اجرا می‌شوند.
