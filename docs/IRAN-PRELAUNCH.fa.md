# بسته آماده‌سازی پیش از انتشار — فقط ایران

وضعیت: **آزمایشی / پیش از انتشار عمومی**. دامنه `transitfuel.ir` در حال ثبت است. درگاه ترکیه در این فاز غیرفعال است.

## آماده شده
- صفحات ایستای معرفی و حریم خصوصی در `public-site/`؛ بدون فرم ورود، ردیاب یا کلید API
- `TRANSIT_COUNTRY_SCOPE` برای شماره‌های +90 به‌صورت پیش‌فرض مسدود است؛ فعال‌سازی ترکیه فقط با مقدار صریح `iran-and-turkey` و پس از قرارداد درگاه جداگانه مجاز است
- قالب تست `123456` فقط با `TRANSIT_SMS_ENV=sandbox` قابل استفاده است و **هیچ پیامکی واقعاً ارسال نمی‌شود**
- آزمون‌های `node --test`، کنترل‌های تأیید دومرحله‌ای و آزمون فایل سایت
- ابزار نسخه پشتیبان آنلاین از SQLite، با بررسی `PRAGMA integrity_check`؛ پشتیبان حاوی داده حساس است
- بسته ZIP صفحات عمومی و SHA256 در مسیر مستقل `I:\TransitFuel-SMS-Test\releases`

## اجرای یکباره در ویندوز
در پنجره PowerShell دوم (نه پنجره سرور در حال اجرا)، از مسیر:
```powershell
Set-Location 'I:\TransitFuel-SMS-Test\app'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'GIT_PULL_FAILED' }
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\finish-iran-prelaunch.ps1'
if ($LASTEXITCODE -ne 0) { throw 'PRELAUNCH_FAILED' }
```
در پایان `PRELAUNCH_IRAN_RESULT: PASS` و مسیر بسته و پشتیبان چاپ می‌شود. **این فرمان سرور را بازراه‌اندازی نمی‌کند یا فایل‌های تولید را روی اینترنت قرار نمی‌دهد.** سرور فعلی تا راه‌اندازی مجدد از کد قدیمی استفاده می‌کند.

## باقی‌مانده پس از ثبت دامنه
1. انتخاب میزبانی مستقل؛ انتشار صفحات از `public-site/`، تنظیم DNS و گواهی HTTPS معتبر
2. تکمیل صفحه حریم خصوصی با اطلاعات تماس واقعی، میزبان، نگه‌داری داده و رویه پشتیبانی پیش از معرفی به SMS.ir
3. ارسال دوباره قالب `488043` با لینک واقعی سایت؛ **فقط پس از تأیید شماره قالب و نام متغیر دقیق** وارد تنظیمات عملیاتی شود
4. ایجاد کلید **عملیاتی** SMS.ir، نه Sandbox؛ آزمون دریافت کد روی موبایل واقعی ایرانی و ورود کامل سه نقش
5. بررسی جداگانه امنیت، دسترسی مدیر، حریم خصوصی، پشتیبان و بازگردانی واقعی در محیط کنترل‌شده، قبل از انتشار نرم‌افزار
6. تصمیم درباره بستر اجرا و تست HTTPS reverse proxy، نسخه پایگاه داده و سیاست مدیریت اطلاعات؛ هیچ تنظیمی از HeavyDriver کپی نشود

## مواردی که نباید انجام شوند
- افزودن کلید API به GitHub، فایل ZIP عمومی، نسخه فرانت‌اند، تصویر یا چت
- تنظیم قالب `123456` در نسخه عملیاتی
- تغییر DNS، Caddy، سرور یا SMS قالب‌های HeavyDriver
- انتقال دیتابیس آزمایشی و شماره ساختگی `+989120000000` به محیط عملیاتی
- فعال‌سازی شماره‌های ترکیه در این مرحله

نسخه عمومی **هنوز آماده انتشار نیست**؛ خروجی بسته صرفاً برای آماده‌سازی و تأیید نهایی است.

## چندزبانه — مرحله اول (پس از ریستارت ویندوز)

- زبان‌های رابط: **فارسی، انگلیسی، ترکی استانبولی و عربی**. جهت متن فارسی/عربی راست‌به‌چپ و انگلیسی/ترکی چپ‌به‌راست است.
- تغییر زبان در سربرگ برنامه انجام می‌شود؛ انتخاب زبان فقط روی همان مرورگر ذخیره می‌شود و باعث تغییر نرخ‌ها، محاسبات، داده سفر یا ارسال SMS نمی‌شود.
- در این مرحله **فرم‌های اصلی سفر و ورود، نام نقش‌ها، خطاهای اصلی و صفحه‌های سایت معرفی** ترجمه شده‌اند؛ ترجمه تمام جزئیات مالی، تمام گزارش‌های تولیدشده و راهنمای داخلی هنوز کامل نیست. بنابراین قابلیت چندزبانه فعلاً در حد **نسخه آزمایشی رابط** است و نباید آن را ترجمه کامل برنامه معرفی کرد.
- سایت معرفی چهار زبان را در مسیر `public-site/index.html`، `index.en.html`، `index.tr.html` و `index.ar.html` به همراه صفحه‌های حریم خصوصی مجزا دارد.
- پشتیبانی نمایشی از ترکی استانبولی **به معنی فعال‌شدن پیامک ترکیه نیست**؛ ارسال OTP به +90 به‌صورت پیش‌فرض غیرفعال است.
- پس از هر تغییر در شاخه توسعه و ریستارت ویندوز، دستورات زیر را در PowerShell معمولی اجرا کنید؛ این فرایند خودکار روی Boot نصب نمی‌شود و کلید Sandbox در تاریخچه فرمان ذخیره نمی‌شود:

```powershell
Set-Location 'I:\TransitFuel-SMS-Test\app'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'UPDATE_FAILED' }
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\finish-iran-prelaunch.ps1'
if ($LASTEXITCODE -ne 0) { throw 'CHECK_FAILED' }
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\start-sandbox-iran.ps1'
```

در پایان تست‌ها، پنجره PowerShell سرور باز می‌ماند و `http://localhost:8112` فقط روی کامپیوتر خودتان قابل مشاهده است. برای بازکردن سرور بعد از ریستارت در آینده کافی است خط آخر را اجرا کنید (به شرط اینکه قبلاً کد به‌روز شده باشد). به هیچ عنوان کلید API را در چت نفرستید.


## اصلاح یکجای چندزبانه — ۲۸ نوامبر ۲۰۲۶

مشکل صفحه انگلیسی که ترکیبی از فارسی و انگلیسی بود در شاخه توسعه اصلاح شده است:
- واژگان تمام برچسب‌های ثابت محتوای `index.html` (به جز مقادیر نمونه محاسباتی) در کاتالوگ‌های ترجمه پوشش دارند.
- ترجمه فارسی، انگلیسی، ترکی استانبولی و عربی برای فرم سفر، سوخت، نرخ ارز، جریمه/خرید مرزی، هزینه‌ها، تأیید نهایی، بازخورد، ورود و مدیریت شرکت موجود است.
- اعداد و واحدهای نمایشی، تاریخ‌ها، پیام‌های هشدار و پنجره‌های تأیید مطابق زبان نمایش داده می‌شوند. **اعداد اصلی، تاریخ ISO، مبالغ، شناسه‌ها و ورودی کاربر تغییر نمی‌کنند**.
- عنوان‌های گزارش TXT، CSV، چاپ و PNG و جهت چیدمان PNG از زبان رابط پیروی می‌کنند. جلوگیری از افشای داده خصوصی راننده پیش از ترجمه خروجی انجام می‌شود.
- متن نمونه سفر مانند نام مسیر «بازرگان/مرسین» و نام پلاک/توضیحی که کاربر یا نمونه آموزشی وارد کرده است عمداً ترجمه خودکار نمی‌شود تا داده اصلی تحریف نشود.
- صفحات معرفی سایت و حریم خصوصی برای هر چهار زبان در `public-site/` آماده‌اند. فعال‌شدن زبان ترکی/عربی به معنی فعال‌شدن ارسال پیامک بین‌المللی نیست.
- صحت نحوی JavaScript و نمونه آزمایش مستقیم چهار زبان بررسی شده است؛ تأیید نهایی `node --test` روی نسخه به‌روز ویندوز کاربر انجام می‌شود. ترجمه گزارش‌های حقوقی/مالی و خروجی‌های حساس پیش از انتشار عمومی باید توسط فرد مسلط به هر زبان بازبینی شود.

### دستور واحد بعد از اصلاحات

```powershell
Set-Location 'I:\TransitFuel-SMS-Test\app'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'UPDATE_FAILED' }
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\update-and-start-iran.ps1'
```

این دستور نخست `node --test` و پشتیبان‌گیری پایگاه داده آزمایشی را انجام می‌دهد، فایل ZIP سایت را می‌سازد، سپس فقط پردازش Node تأییدشده روی پورت `8112` را متوقف و سرور جدید Sandbox را با درخواست محرمانه کلید آزمایشی روشن می‌کند. هیچ دامنه، سرور عملیاتی یا فایل HeavyDriver تغییر داده نمی‌شود.
