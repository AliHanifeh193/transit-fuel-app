# بسته آماده‌سازی پیش از انتشار — فقط ایران

وضعیت: **آزمایشی / پیش از انتشار عمومی**. دامنه `transitfuel.ir` در حال ثبت است. درگاه ترکیه در این فاز غیرفعال است.

## آماده شده
- صفحات ایستای معرفی و حریم خصوصی در `public-site/`؛ بدون فرم ورود، ردیاب یا کلید API
- `TRANSIT_COUNTRY_SCOPE` برای شماره‌های +90 به‌صورت پیش‌فرض مسدود است؛ فعال‌سازی ترکیه فقط با مقدار صریح `iran-and-turkey` و پس از قرارداد درگاه جداگانه مجاز است
- قالب تست `123456` فقط با `TRANSIT_SMS_ENV=sandbox` قابل استفاده است و **هیچ پیامکی واقعاً ارسال نمی‌شود**
- آزمون‌های `node --test`، کنترل‌های تأیید دومرحله‌ای و آزمون فایل سایت
- ابزار نسخه پشتیبان آنلاین از SQLite، با بررسی `PRAGMA integrity_check`؛ پشتیبان حاوی داده حساس است
- بسته ZIP صفحات عمومی و SHA256 در مسیر مستقل `I:\TransitFuel-SMS-Test\releases`

## اجرای یکباره در ویندوز
در پنجره PowerShell دوم (نه پنجره سرور در حال اجرا)، از مسیر:
```powershell
Set-Location 'I:\TransitFuel-SMS-Test\app'
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'GIT_PULL_FAILED' }
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\finish-iran-prelaunch.ps1'
if ($LASTEXITCODE -ne 0) { throw 'PRELAUNCH_FAILED' }
```
در پایان `PRELAUNCH_IRAN_RESULT: PASS` و مسیر بسته و پشتیبان چاپ می‌شود. **این فرمان سرور را بازراه‌اندازی نمی‌کند یا فایل‌های تولید را روی اینترنت قرار نمی‌دهد.** سرور فعلی تا راه‌اندازی مجدد از کد قدیمی استفاده می‌کند.

## باقی‌مانده پس از ثبت دامنه
1. انتخاب میزبانی مستقل؛ انتشار صفحات از `public-site/`، تنظیم DNS و گواهی HTTPS معتبر
2. تکمیل صفحه حریم خصوصی با اطلاعات تماس واقعی، میزبان، نگه‌داری داده و رویه پشتیبانی پیش از معرفی به SMS.ir
3. ارسال دوباره قالب `488043` با لینک واقعی سایت؛ **فقط پس از تأیید شماره قالب و نام متغیر دقیق** وارد تنظیمات عملیاتی شود
4. ایجاد کلید **عملیاتی** SMS.ir، نه Sandbox؛ آزمون دریافت کد روی موبایل واقعی ایرانی و ورود کامل سه نقش
5. بررسی جداگانه امنیت، دسترسی مدیر، حریم خصوصی، پشتیبان و بازگردانی واقعی در محیط کنترل‌شده، قبل از انتشار نرم‌افزار
6. تصمیم درباره بستر اجرا و تست HTTPS reverse proxy، نسخه پایگاه داده و سیاست مدیریت اطلاعات؛ هیچ تنظیمی از HeavyDriver کپی نشود

## مواردی که نباید انجام شوند
- افزودن کلید API به GitHub، فایل ZIP عمومی، نسخه فرانت‌اند، تصویر یا چت
- تنظیم قالب `123456` در نسخه عملیاتی
- تغییر DNS، Caddy، سرور یا SMS قالب‌های HeavyDriver
- انتقال دیتابیس آزمایشی و شماره ساختگی `+989120000000` به محیط عملیاتی
- فعال‌سازی شماره‌های ترکیه در این مرحله

نسخه عمومی **هنوز آماده انتشار نیست**؛ خروجی بسته صرفاً برای آماده‌سازی و تأیید نهایی است.
